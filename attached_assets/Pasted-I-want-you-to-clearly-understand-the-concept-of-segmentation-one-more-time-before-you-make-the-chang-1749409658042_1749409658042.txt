Now, coming to the UI implementation this is how I thought we should establish the workflow in 'Segmentation & Mapping' tab.

- User first selects audio file from dropdown, to start media segmentation. Selected audio file will load into the player. 
- The audio player will have the audio track controls as the selected audio plays. 
- It will have these control buttons Play/Pause, Stop, MarkTime, ClearMark, ClearAllMarks.
- Play/Pause button will play/pause the audio from/at the cursor's position on the audio track line. 
- Stop will completely stop playing audio and return the playback position to beginning. 
- MarkTime button will mark a point on the track at the current playback position. As the audio is playing on the track, user can click this button multiple times to mark points at various positions on the track as it is played.
- User can select a specific mark on the track and clear it by clicking ClearMark. Where as ClearAllMarks will clear all the marks set on the track. 
- Once user has set marks across the track, they will have a button 'Create audio segments'. Clicking this will autiomatically create audio segments in the MediaSegments db table based on the marks they have set on the audio track. 
- For example, imagine the audio track is 0.00 secs to 40.34 secs and User has set marks at following timestamps on the track. timestamp#1 - 1.57 secs, timestamp#2 - 4.07 secs, timestamp#3 - 10.87. When user clicks 'Create audio segments' button, you should create audio segments into the database with the appropriate start and end timestamps as following. Segment#1 - 0.00 to 1.57 secs, Segment#2 - 1.57 secs to 4.07 secs, Segment#3 - 4.07 secs to 10.87 secs, Segment#4 - 10.87 secs to 40.34 secs. 
- All the created audio segments load into a separate 'Audio Segments' panel below. 
- In the 'Audio Segments' panel, user will have a play option which will play the selected media segments in the audio player above. There should be an option for user to delete the media segment and also modify the start and end timestamps of the audio segement.
