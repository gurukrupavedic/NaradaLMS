# Experiments Directory

This directory contains isolated experiments and prototypes that can be safely deleted without affecting the main Vedic LMS application.

## Current Experiments

### DaisyUI Theme Migration (`daisyui-examples/`)
- Complete visual examples of migrating from shadcn/ui to DaisyUI with pastel theme
- Shows dashboard, chapter editor, and forms with enhanced styling
- Custom Vedic color extensions (saffron/gold accents)
- Accessible via Experiments tile in main dashboard

## Safety
- All experiments are completely isolated from production code
- Static HTML files served independently
- Zero impact on main application functionality
- Safe to delete entire directory at any time

## Access
- Main experiments page: `/experiments/daisyui-showcase`
- Direct HTML examples: `/experiments/01-dashboard-comparison.html`, etc.
- Linked from Experiments tile on dashboard
