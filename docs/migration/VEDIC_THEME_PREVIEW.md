# Vedic LMS with DaisyUI Pastel Theme - Visual Preview

## Theme Overview

The **DaisyUI Pastel theme** provides the perfect foundation for your Vedic LMS application, offering:

- **Soft, calming colors** that promote focus and learning
- **Excellent readability** for multi-script content (Telugu, Hindi, English)
- **Cultural harmony** with gentle tones that complement Vedic philosophy
- **Professional aesthetics** suitable for educational institutions
